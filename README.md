# Kevin Bongcawel — Personal Portfolio

Responsive personal portfolio built with Vite, Bootstrap 5, and custom CSS.

## Development
```bash
npm install
npm run dev
```

## Production
```bash
npm run build
npm run preview
```

Cloudflare Pages build command: `npm run build`  
Build output directory: `dist`  
Production branch: `main`

The section structure is based on the About Me Personal Portfolio template by EaseTemplates:
https://github.com/easetemplates/about-me-personal-portfolio-website-template
